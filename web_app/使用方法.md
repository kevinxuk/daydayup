# 家务零花钱打卡 - 使用方法

## 🚀 快速启动

### 方式一：双击启动
双击运行 `start_server.py`，会自动：
1. 检查 Node.js 环境
2. 安装依赖
3. 启动服务器
4. 打开浏览器

### 方式二：命令行启动
```bash
cd C:\Users\Administrator\Documents\1mycode\daydayup\web_app
npm install
npm start
```

然后访问：http://localhost:3000

---

## 📱 使用说明

### 孩子端
1. 打开网页
2. 点击任务方框打勾/取消
3. 自动统计今日收入和本月累计
4. 点击"同步到云端"保存数据

### 家长端
1. 点击右上角「家长端」
2. 输入密码（默认：123456）
3. 审核打卡记录
4. 查看历史记录表格
5. 导出 CSV 数据

## ☁️ 云端同步

### 使用 Supabase（推荐）

1. 访问 https://supabase.com 注册账号
2. 创建新项目
3. 进入 SQL Editor，执行：

```sql
CREATE TABLE IF NOT EXISTS chore_data (
    id INTEGER PRIMARY KEY DEFAULT 1,
    data JSONB NOT NULL,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE chore_data ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read" ON chore_data
    FOR SELECT USING (true);

CREATE POLICY "Allow public update" ON chore_data
    FOR ALL USING (true);

INSERT INTO chore_data (id, data)
VALUES (1, '{"profile":{"name":"小朋友","class":"","password":"123456"},"checks":{},"approvals":[]}')
ON CONFLICT (id) DO NOTHING;
```

4. 获取 API 配置：
   - Settings → API
   - 复制 Project URL 和 anon/public key

5. 在代码中配置 Supabase

## ⚙️ 配置修改

### 修改端口
编辑 `server.js`，修改 PORT 变量：
```javascript
const PORT = process.env.PORT || 3000;
```

### 修改密码
编辑 `index.html`，修改默认密码：
```javascript
let data = { profile: { name: '小朋友', class: '', password: '123456' }, ... };
```

## 🐛 常见问题

### Q: 无法访问 http://localhost:3000
A: 确保服务器已启动，检查端口是否被占用

### Q: 数据不同步
A: 点击"同步到云端"按钮，或检查网络连接

### Q: 密码错误
A: 默认密码是 123456，可在设置中修改
