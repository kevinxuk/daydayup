# 使用方法

## 方式一：本地模式（单机使用）
直接双击打开 `index.html` 即可使用，数据保存在浏览器本地

## 方式二：云端同步模式（多设备）

### 1. 启动服务器
```bash
cd web_app
python start_server.py
```
或
```bash
cd web_app
npm install
npm start
```

### 2. 访问应用
浏览器自动打开：http://localhost:3000

### 3. 多设备同步
1. 在手机/平板上访问同一局域网地址（如 http://192.168.1.100:3000）
2. 或部署到云服务器

### 4. 同步数据
- 点击"同步到云端"保存数据
- 点击"从云端同步"加载数据

## 服务器地址配置
如需更改服务器地址，在浏览器中执行：
```javascript
localStorage.setItem('serverUrl', 'http://你的服务器地址:3000')
```

## 数据备份
所有云端数据存储在 `data/` 目录，备份该目录即可
